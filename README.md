# Portfolio

Şəxsi portfolio veb saytı: sadə HTML, CSS və JavaScript ilə hazırlanıb, heç bir quraşdırma tələb etmir.

## Bölmələr
- Ana səhifə (hero)
- Haqqımda
- Bacarıqlar
- Layihələr
- Təcrübə
- Əlaqə

Açıq və tünd mövzu dəstəklənir, sayt mobil cihazlara uyğundur.

## Öz məlumatlarınızı necə yazmaq olar
Bütün mətnlər `index.html` faylındadır. "Adınız Soyadınız", `email@example.com` və layihə təsvirlərini öz məlumatlarınızla əvəz edin. Rənglər `style.css` faylının əvvəlindəki `:root` blokundadır.

## Lokal baxış
`index.html` faylını brauzerdə açın.

## Yayımlamaq (GitHub Pages, pulsuz)
1. Repo-da **Settings → Pages** bölməsinə keçin.
2. **Source** üçün "Deploy from a branch", branch üçün `main` və `/ (root)` seçin, sonra **Save** basın.
3. Bir neçə dəqiqədən sonra sayt `https://lumeriaapp.github.io/aaad/` ünvanında açılacaq.
